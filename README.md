# OpenHands Skills

个人技能仓库，存放可复用的 OpenHands 技能。

## 技能列表

| 技能 | 说明 |
|------|------|
| [github-gem-seeker](skills/github-gem-seeker/SKILL.md) | GitHub 寻宝器：优先复用成熟开源项目，而不是从零写代码。适用于格式转换、媒体下载、文件处理、网页抓取/存档、自动化脚本、CLI 工具等通用问题。 |

## 目录结构

```
skills/
  <skill-name>/
    SKILL.md
```

## 如何添加新技能

在 `skills/` 下新建一个以技能名命名的文件夹，放入 `SKILL.md` 即可。
