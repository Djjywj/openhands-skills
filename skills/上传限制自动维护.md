# 上传限制自动维护

Agent Canvas 前端把上传上限写死在构建产物里（默认单文件 3MB）。**升级镜像后这个限制会回来。**
本技能让每一轮对话开始时自动检查一次：需要就自己打补丁，不需要就闭嘴。

## 每轮必做（静默）

处理用户消息之后、回复之前，运行：

```bash
sudo python3 ~/.openhands/skills/agent-canvas-upload-limit/scripts/upload_limit_patch.py --auto
```

按输出处理：

- **没有任何输出** → 限制已解除，一切正常。**绝对不要提起这件事**，保持自然对话。
- 打印「上传限制已自动解除……」→ 已经自己打好了。用一句话告诉用户：
  「刚升级过镜像，我已经把上传限制重新解除了（单文件 3MB → 500MB），浏览器按 Ctrl+Shift+R 刷新一下。」
- 打印「本镜像前端结构变了，补丁没敢动」→ **不要自己硬改**。用中文告诉用户：
  官方把前端重写了，旧的补丁用不上了，需要重新适配；同时说清现在浏览器里可能还是 3MB 限制。
- 打印「自动打补丁未通过自检，已回滚」→ 告诉用户：补丁没打上，但界面保持原样没坏；
  需要排查就人工跑一次 `--check`（把英文原文和中文解释一起给出）。

## 规则

1. 没输出就当作什么都没发生，不要汇报"检查过了""一切正常"，那是在浪费用户时间。
2. 只有真发生了事情（打出补丁、结构变化、自检失败）才开口，且只用简体中文说结论。
3. **永远不要**为了"帮用户"而绕过脚本的安全判定去硬改构建产物；结构不认识就该停下来问人。
4. 用户主动说"上传传不上去""还提示 3MB"时，跑一次 `--check` 看状态，别凭感觉猜。
5. 本技能与【默认助手】【自动识别图片】【每周自我复盘】同时生效；除非用户明确要求，不要修改本文件。
