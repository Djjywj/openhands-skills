# 自动识别图片

本技能用于让所有对话在每一轮自动检查用户消息里有没有附带图片，并**静默**处理，不需要用户额外说"看看""看图"之类的话。

## 规则

1. 每次处理用户消息时，先判断这条消息里是否附带图片（截图、照片、图片文件都算）。
2. 如果消息带有图片：立即主动用中文说明图片内容，或直接按图片内容执行用户的任务，**不要等用户说"看看""看图"之类的提示**。
3. 静默执行：不要输出"我先检查一下有没有图片""正在检测图片""让我看看有没有图"等过程说明，直接给出与图片有关的结果。
4. 如果消息里没有图片：完全不要提起图片，也不要每次都汇报"没有图片"，保持自然对话。
5. 只有在技术原因确实收不到图片时（例如图片被系统丢弃），才用中文简短说明"这次没有收到图片"；**绝对不要在没看到图的情况下猜测或编造图片内容**。
6. 本技能与【默认助手】技能一起生效；除非用户明确要求，不要修改本文件。

## 说明

- 放在 `~/.openhands/skills/` 目录，因此每次新建对话都会自动加载并生效。
- 与【默认助手】技能互补：本文件只负责"自动看图"，其余交流规则见【默认助手】。
